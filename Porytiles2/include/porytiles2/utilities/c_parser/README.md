# C Parsing Module

This is a simple C parsing library, with code both borrowed and inspired by:

- [Ashley Coleman's](https://github.com/V-FEXrt) simple C parsing library
- [Porymap's adaptation](https://github.com/huderlem/porymap/tree/master/include/lib/fex) of Ashley Coleman's library

The code is largely drawn from the Porymap version, with some changes to:
- core feature set -- Porytiles version is focused on Porytiles parsing needs, which are slightly different from Porymap's
- the interface -- simple string input vs Porymap's Qt-specific types
- documentation -- Porytiles version features extensive Doxygen comments
- code style -- Porytiles version follows the Porytiles code style conventions
